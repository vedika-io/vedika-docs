# SDK Documentation

Official JavaScript and Python SDKs for the Vedika API. Type-safe, fully documented, with built-in error handling.

## JavaScript SDK

@vedika-io/sdk on npm

`npm install @vedika-io/sdk`

[Quickstart](https://vedika.io/docs/sdk/quickstart) | [Auth](https://vedika.io/docs/sdk/authentication) | [Streaming](https://vedika.io/docs/sdk/streaming) | [Errors](https://vedika.io/docs/sdk/error-handling)

## Python SDK

vedika-sdk on PyPI

`pip install vedika-sdk`

[Quickstart](https://vedika.io/docs/sdk/python-quickstart) | [Auth](https://vedika.io/docs/sdk/python-auth) | [Charts](https://vedika.io/docs/sdk/python-charts)
